**COMMENT TOXICITY DETECTION**

This Project uses a Deep-Learning model to identify and flag toxic comments based on the online comments dataset.
A Bi-directional LSTM architecture is used for this project.
The Basic workflow of the project :
- Data exploration
- Data pre-processing and cleaning
- Tokenization and sequence padding
- Defining the model architecture
- Training the LSTM model
- Evaluating the model
- pickling
